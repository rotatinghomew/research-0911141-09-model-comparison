# 可复核的候选比较

页面上的“各候选描述”只是浏览用的描述值；真正的候选比较在“候选比较”区域。它回答四件事：差异有多大、不确定性多大、差异来自数据集之间还是重复分折、以及推理成本与漏判代价是否可接受。

## 比较单元

- 一行 prediction 是某 candidate 在某个 split 下对一个 observation 的预测。同一 observation 会在重复分折里出现多次，因此 **预测行数不是样本量**。
- 测试集完全相同的重复分折被合并成一个“分折簇”（`cluster`），例如 `short_tasks_0_0` 与 `short_tasks_1_0` 共享同一测试集，合为 `short_tasks/short_tasks_row_00+10`。
- 簇内先对重复折取平均，再按簇等权汇总。一个簇内的不同 observation 共享同一组学生，区间还要按 subject 聚类。
- 每个簇的组成（包含哪些 split、repeat、fold、release）和每个候选的覆盖在 `folds` 中原样列出，便于核对。

## 缺折候选

候选只有在一个簇内完整覆盖该簇全部测试观测时，这个簇才进入它的比较：

- `coverage` 给出每个候选的单元数与覆盖率，并逐簇区分 `clusters_full`、`clusters_partial`、`clusters_absent`。
- 每个候选对只在双方都完整覆盖的簇上做配对差异；其余簇列入 `excluded_clusters`，不会因为某个候选缺折而悄悄缩小到有利子集。
- 配对汇总用的 `joint_support`（所有冻结候选都完整覆盖的簇）与各候选自身覆盖分开报告。业务取舍（漏判率、时延、覆盖率）按候选自身完整覆盖的簇评估。
- 覆盖率低于冻结下限或存在被排除的簇时，该候选对不能成为确认性结论。

## 不确定性与结论

- 配对差异区间来自双重聚类 bootstrap：同时重采样分折簇与 subject。重复分折不会增加有效样本，只会缩小表面方差；`decomposition` 给出重复折标准差占簇间方差的比例。
- 结论允许是“不足以区分”。两侧区间都越过最小实际差异（`min_effect`，默认 0）才算可区分；否则如实报告没有可证实差异。
- `decomposition.dataset_breakdown` 与 `between_dataset_share` 把簇间差异拆成数据集之间与数据集内部；不会把三个数据集当成一个大池子直接排名。
- `business_cost` 指标把漏判、误报和推理时延合成成本，数值越低越好；`advantage` 已统一为“正值表示左侧候选更好”。约束字段 `max_fn_rate`、`max_mean_latency_ms`、`min_coverage` 用于业务取舍，不通过约束的候选即使指标更高也不进入 `acceptable`。

## 冻结与证据等级

冻结记录保存：候选集合、指标与全部成本参数、阈值、覆盖率下限、证据范围（数据版本 + 数据集选择）以及当时的证据范围指纹。此后：

- 若比较的规格、范围或数据版本与冻结记录一致，沿用冻结时的证据等级；只要不一致，登记为 `deviated`，只能作事后探索。
- 冻结前若已存在同范围保存过的比较记录，冻结本身会被标为探索性。
- 证据是否独立按发布（`release`）判断：某发布上发生过改指标事件，或有候选在该发布之后加入（`created_after_release`），这个发布就被视为已参与选型，不能算未受影响的后续资料。
- 只有冻结状态为 `confirmatory` 且该候选对在独立簇上也能估计不确定性时，比较才标为确认性。整体状态为 `confirmatory`、`mixed` 或 `exploratory`，逐对状态在 `pairs[].evidence`。
- 现实材料常常只能给出探索性结论；“不足以区分”与“探索性”都是可接受的结论。

## 原始误判与分折归属

`misjudgments` 列出每个候选的实际漏判与误报，含 split_id、repeat、fold、release、observation_id、subject_id、truth、score 与 latency_ms，可按候选筛选查看。超过 2000 行会截断显示（区间仍基于完整数据）。

## 保存的比较材料

保存的比较记录保存当时的规格、注册状态、证据等级与完整结果，不随后续导入变化；重新读取时保持原样。比较记录不能替代冻结记录：冻结应在看到比较结果之前完成。
